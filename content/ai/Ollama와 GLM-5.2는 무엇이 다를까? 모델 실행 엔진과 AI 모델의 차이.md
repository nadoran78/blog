
개방형 모델을 맥미니에서 실행할 수 있는지 알아보다가 Ollama와 GLM-5.2를 비교하게 되었다.

처음에는 둘 다 비슷한 종류의 AI라고 생각했지만, 실제로는 서로 역할이 완전히 다르다.

간단히 말하면 다음과 같다.

```
Ollama
= AI 모델을 실행하는 도구

GLM-5.2
= Ollama 같은 도구나 클라우드에서 실행되는 AI 모델
```

자동차에 비유하면 Ollama는 자동차를 움직이는 엔진이나 운행 환경에 가깝고, GLM-5.2는 그 환경에서 사용하는 특정 모델이라고 이해할 수 있다.

## Ollama는 AI 모델이 아니다

Ollama는 LLM을 다운로드하고 실행할 수 있도록 도와주는 모델 실행 도구다.

터미널에서 다음과 같은 명령을 실행하면 지원되는 모델을 내려받아 사용할 수 있다.

```
ollama run llama3.2
```

Ollama가 제공하는 주요 기능은 다음과 같다.

- 모델 다운로드와 관리
- 로컬 환경에서 모델 실행
- 대화형 CLI 제공
- HTTP API 제공
- 모델별 설정 관리
- 애플리케이션에서 모델을 호출할 수 있는 실행 환경 제공

즉, Ollama 자체가 질문에 답하는 것은 아니다.

실제로 답변을 만드는 것은 Ollama를 통해 실행한 Llama, Qwen, Gemma 등의 모델이다.

```
사용자 또는 애플리케이션
          ↓
       Ollama
          ↓
     Llama, Qwen 등
          ↓
        응답
```

Ollama는 모델과 애플리케이션 사이에서 모델을 실행하고 요청을 전달하는 역할을 한다.

## GLM-5.2는 AI 모델이다

GLM-5.2는 Z.ai가 공개한 대규모 언어 모델이다.

따라서 Ollama와 GLM-5.2를 직접 비교하는 것은 정확하지 않다.

비교하려면 다음과 같이 구분해야 한다.

```
Ollama ↔ LM Studio, llama.cpp, vLLM
```

이들은 모델을 실행하고 제공하는 도구 또는 런타임에 가깝다.

반면 다음은 실제 언어 모델이다.

```
GLM-5.2 ↔ Llama ↔ Qwen ↔ Gemma ↔ DeepSeek
```

즉, Ollama와 GLM-5.2의 관계는 경쟁 관계라기보다 실행 도구와 실행 대상의 관계에 가깝다.

## 그렇다면 Ollama로 GLM-5.2를 실행할 수 있을까?

Ollama 모델 라이브러리에는 `glm-5.2:cloud`가 등록되어 있다.

```
ollama run glm-5.2:cloud
```

다만 여기서 `:cloud`가 중요하다.

이 명령은 GLM-5.2 전체를 내 컴퓨터에 내려받아 로컬에서 실행한다는 의미가 아니다. Ollama를 인터페이스로 사용하지만, 실제 모델 추론은 클라우드에서 처리된다.

```
내 컴퓨터
   ↓
Ollama
   ↓
Ollama Cloud
   ↓
GLM-5.2
```

따라서 명령어는 Ollama를 사용하더라도 로컬 모델과 같은 방식은 아니다.

## `glm-5.2:cloud` 호출은 비용이 발생할 수 있다

GLM-5.2가 오픈 웨이트 모델이라고 해서 클라우드 호출까지 항상 무료인 것은 아니다.

오픈 웨이트는 일반적으로 모델의 가중치를 제공된 라이선스에 따라 내려받아 사용할 수 있다는 의미다. 누군가의 GPU 서버를 이용하는 비용까지 무료라는 뜻은 아니다.

`glm-5.2:cloud`는 로컬 자원이 아니라 Ollama의 클라우드 컴퓨팅 자원을 사용하므로 다음 조건의 영향을 받을 수 있다.

- 계정에 제공되는 무료 사용량
- 체험 기간
- 구독 요금제
- 사용량 제한
- 향후 변경되는 클라우드 정책

무료 할당량을 넘거나 이용 조건이 변경되면 비용이 발생할 수 있으므로, 사용하기 전에 Ollama 계정의 현재 요금제와 사용량을 확인해야 한다.

```
오픈 웨이트
= 모델 자체를 이용할 수 있는 라이선스

로컬 실행
= API 호출료는 없지만 내 컴퓨팅 자원을 사용

클라우드 실행
= 서버 사용량에 따라 비용이 발생할 수 있음
```

Z.ai가 제공하는 API나 Coding Plan을 통해 GLM-5.2를 사용하는 경우에도 무료 체험 또는 제공량을 초과하면 유료 과금이 적용될 수 있다.

결국 모델이 공개되어 있다는 사실과 클라우드 API를 무료로 이용할 수 있다는 것은 서로 다른 이야기다.

## GLM-5.2를 맥미니에서 직접 실행할 수 있을까?

현실적으로는 어렵다.

GLM-5.2는 약 7,530억 개의 전체 파라미터를 가진 매우 큰 모델이다. MoE 구조를 사용해 요청을 처리할 때 모든 파라미터가 동시에 활성화되는 것은 아니지만, 전체 가중치를 메모리에 올리기 위한 자원은 여전히 매우 크다.

양자화를 적용하더라도 일반적인 맥미니의 통합 메모리로 실행할 만한 크기가 아니다.

따라서 맥미니에서 다음 명령을 사용한다고 해도,

```
ollama run glm-5.2:cloud
```

맥미니가 GLM-5.2 전체를 직접 실행하는 것은 아니다. 맥미니의 Ollama가 클라우드 모델에 요청을 전달하는 방식이다.

## 맥미니에서는 어떤 모델을 실행하는 것이 현실적일까?

맥미니에서 로컬 모델을 실행하려면 메모리 용량에 맞는 소형 또는 중형 모델을 선택하는 편이 현실적이다.

예를 들면 다음과 같은 모델 계열을 검토할 수 있다.

- Llama 소형 모델
- Qwen 소형 모델
- Gemma 소형 모델
- DeepSeek 계열의 경량 또는 증류 모델
- 그 밖의 4비트 양자화 모델

실행 가능 여부와 속도는 다음 요소에 따라 크게 달라진다.

- 맥미니의 칩
- 통합 메모리 용량
- 모델의 파라미터 수
- 양자화 수준
- 컨텍스트 길이
- 동시에 처리하는 요청 수

모델이 실행된다는 것과 실용적인 속도로 서비스할 수 있다는 것도 구분해야 한다.

개인 실험이나 저빈도 요청에는 사용할 수 있어도, 여러 사용자가 동시에 접근하는 서비스라면 응답 속도와 동시 처리량이 부족할 수 있다.


## 어떤 방식을 선택하면 될까?

개인정보 보호와 호출 비용 절감이 중요하고 비교적 단순한 작업이라면 소형 모델을 맥미니에서 직접 실행하는 방식이 적합할 수 있다.

```
Ollama
+
맥미니에서 실행 가능한 소형 모델
```

반면 복잡한 추론이나 높은 품질이 필요하다면 클라우드 모델을 사용하는 편이 현실적이다.

```
Ollama
+
glm-5.2:cloud
```

단, 이 경우에는 로컬 실행이 아니며 무료 사용량을 초과하면 비용이 발생할 수 있다는 점을 고려해야 한다.

실제로는 두 방식을 함께 사용하는 것도 가능하다.

```
간단한 분류와 요약
→ 맥미니의 로컬 소형 모델

복잡한 분석과 코드 생성
→ GLM-5.2 같은 클라우드 모델
```

이런 구조라면 비용과 성능을 작업에 따라 조절할 수 있다.

## 정리

처음에는 Ollama와 GLM-5.2가 경쟁하는 AI 제품이라고 생각했다.

하지만 실제로는 서로 다른 계층에 있다.

```
Ollama
= 모델 실행 및 호출 환경

GLM-5.2
= 언어를 이해하고 응답을 생성하는 모델
```

그리고 Ollama에서 `glm-5.2:cloud`를 사용할 수 있다고 해서 GLM-5.2가 맥미니 안에서 실행되는 것도 아니며, 영구적으로 무료라는 뜻도 아니다.

개방형 모델을 활용할 때는 다음 세 가지를 구분해서 봐야겠다.

```
모델은 공개되어 있는가?

내 컴퓨터에서 실행할 수 있는 크기인가?

클라우드 호출에는 얼마의 비용이 드는가?
```

나중에 맥미니를 AI 서버로 활용하게 된다면, 처음부터 GLM-5.2 같은 초대형 모델을 직접 구동하기보다 Ollama와 작은 로컬 모델로 간단한 요약·분류 서비스를 먼저 만들어보는 편이 현실적일 것 같다.

필요할 때만 GLM-5.2 같은 클라우드 모델을 호출하는 방식도 함께 검토해볼 수 있겠다.
